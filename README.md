# cad-layout-pdf-merger
AutoCAD 배치탭 하나에 격자로 놓인 도면 여러 장을, 장마다 A3 PDF로 출력한 뒤 한 파일로 합치는 프로그램입니다.
AutoCAD LT와 정식 AutoCAD 모두에서 쓸 수 있습니다.

- `lisp\zframe.lsp` : AutoCAD에서 불러 쓰는 프로그램
- `lisp\zfmerge.exe` : PDF 합치기 프로그램. `zframe.lsp`가 자동으로 실행합니다.
- 이 설명은 `lisp\처음설정_사용법.txt`에도 같은 내용으로 들어 있습니다.

---

## 1. 처음 쓰는 PC에서 한 번만 할 일

### ① AutoCAD 버전 확인
- AutoCAD LT는 **2024 이상**이어야 합니다. LT 2023 이하에는 LISP 기능이 없습니다.
- 확인 방법: AutoCAD 오른쪽 위 **?** → **AutoCAD LT 정보**

### ② 파일 받기
1. 아래 주소를 클릭해서 ZIP 파일을 받습니다.
   https://github.com/xodbs3355-sudo/cad-layout-pdf-merger/archive/refs/heads/main.zip
2. ZIP 파일을 **다운로드 폴더에 압축 풀기** 합니다.
   - 풀고 나면 `다운로드\cad-layout-pdf-merger-main\lisp` 폴더 안에 `zframe.lsp`, `zfmerge.exe`가 있습니다.
   - 다른 폴더에 풀어도 되지만, 그 경우 ③에서 그 폴더를 등록해야 합니다.

### ③ [필수] `lisp` 폴더를 "신뢰할 수 있는 위치"로 등록
이걸 안 하면 로드할 때 `파일 로드 취소됨` 오류가 납니다(AutoCAD 보안 기능).
1. AutoCAD 명령창에 `OPTIONS` 입력 → Enter
2. **파일** 탭 → **신뢰할 수 있는 위치** 선택 → **추가** → **찾아보기**
3. `다운로드\cad-layout-pdf-merger-main\lisp` 폴더 선택 → **확인** → **확인**
   - "폴더가 읽기 전용이 아니다"는 경고가 나오면 확인을 누르고 진행합니다.

### ④ [필수] PDF가 만들어질 때 자동으로 열리지 않게 설정
이걸 안 하면 장마다 Edge(PDF 뷰어)가 열리고, 그 때문에 합친 뒤 개별 PDF가 지워지지 않습니다.
1. AutoCAD에서 **Ctrl + P** (플롯 창)
2. **프린터/플로터 이름**에서 `DWG To PDF.pc3` 선택
3. **PDF 옵션** 버튼 → 맨 위 **뷰어에 결과 표시** 체크 **끄기** → **확인**
4. "프린터 구성 파일 변경" 창에서 **변경 사항을 다음 파일로 저장** 선택 → **확인**
5. 플롯 창은 **취소**
   - 이후 손으로 PDF를 출력할 때도 자동으로 열리지 않습니다.

### ⑤ (참고) 처음 `zfmerge.exe`가 실행될 때
- 브라우저가 내려받을 때 "일반적으로 다운로드되지 않는 파일" 경고를 띄우면: 그 항목의 **⋯** → **유지**
- Windows가 "PC 보호" 창으로 실행을 막으면: **추가 정보** → **실행** (이 창이 실제로 뜨는지는 확인하지 못했습니다)

## 2. 매번 쓰는 순서

1. 도면을 열고 프레임이 있는 **배치탭**으로 갑니다.
   - 뷰포트 안이 활성 상태면 뷰포트 바깥을 더블클릭해서 빠져나옵니다.
2. `APPLOAD` → `lisp` 폴더의 `zframe.lsp` 선택 → **로드** → **닫기**
   - AutoCAD를 새로 켤 때마다 한 번 필요합니다.
3. `PDFMERGE` 입력 → Enter
4. 노란 ㄱ자 표시 하나를 클릭합니다(어느 모서리 것이든 상관없음).
5. 도면에 빨간 번호가 붙습니다(미리보기). 순서와 개수를 확인합니다.
   - 번호가 안 붙고 `?`가 붙은 프레임은 ㄱ자가 하나 빠진 것입니다. 이 프레임은 출력되지 않습니다.
6. **출력할 번호**: Enter = 전체. 일부만 하려면 `1-5,8`처럼 입력
7. **저장 창**: 합친 PDF의 이름과 위치를 정합니다.
   - 같은 이름 파일이 있으면 덮어쓸지 묻습니다(기본값: 덮어쓰지 않음).
8. **진행할까요?** → Enter
9. 한 장씩 출력된 뒤, 잠시 후 **"합치기 완료"** 메시지 창이 뜹니다.
   - 개별 PDF는 자동으로 지워지고, 빨간 번호 표시도 자동으로 지워집니다.

### 명령
명령은 `PDFMERGE` 하나입니다.
- 번호 미리보기와 함께, 명령창에 찾은 결과(ㄱ자 후보·탈락 사유, 꼭짓점 개수, 프레임 좌표, 실패)를 보여 줍니다. 문제가 생기면 이 내용을 확인합니다.
- 일부만 출력하려면 "출력할 번호"에 `1-5,8`처럼 입력합니다. 1장만 시험하려면 `1`을 입력합니다.

### 출력 설정 (고정)
- 프린터 `DWG To PDF.pc3`, 용지 `ISO 전체 페이지 A3(420.00 x 297.00 mm)` 가로
- 프레임 가로가 용지 가로(420mm)에 꽉 차게 맞춤. 비율 차이로 위아래에 약간 여백이 생길 수 있음
- 바꾸려면 `zframe.lsp` 안의 `*ZF-PLOTTER*`, `*ZF-PAPER*`, `*ZF-CTB*` 값을 고칩니다.

## 3. 문제가 생겼을 때

| 증상 | 원인과 해결 |
|---|---|
| `파일 로드 취소됨` | ③ 신뢰할 수 있는 위치 등록이 안 됨 |
| 번호 대신 `?` 표시, "실패 ... 짝 없음" | 그 프레임의 ㄱ자가 빠짐. 도면에 ㄱ자를 추가하고 다시 실행 |
| 합친 뒤 개별 PDF(`zf_시각_번호.pdf`)가 남음 | ④ 뷰어 설정 확인. Edge 등에서 그 PDF를 열고 있으면 닫고 직접 지움. 자세한 원인은 `lisp\zfmerge_log.txt` |
| `zfmerge.exe 위치를 선택하세요` 창이 뜸 | `zfmerge.exe`가 `zframe.lsp`와 같은 폴더(신뢰 위치)에 없음. 그 폴더에 두거나, 창에서 직접 고름 |
| ZIP 압축 풀기 중 "다른 프로세스가 사용 중" | AutoCAD에 `docs\zframe_test.dxf`가 열려 있음. 닫고 다시 풀기 |
| 그 밖의 오류 | AutoCAD에서 **F2**를 눌러 명령창 기록(`[PDFMERGE]` 줄)을 캡처 |

## 알려진 제약
- ㄱ자 표시가 점 3개짜리 폴리선(LWPOLYLINE)인 도면을 기준으로 만들었습니다. 선 2개로 된 ㄱ자나 블록 안의 ㄱ자는 찾지 않습니다.
- 도면 안에 견본과 같은 색·같은 크기의 ㄱ자 폴리선이 따로 있으면 잘못된 프레임이 생길 수 있습니다. 번호 미리보기에서 확인하십시오.
- 개발 기록과 시험 코드는 `docs`, `tests`, `tools` 폴더에 있습니다. 사용에는 필요 없습니다.
